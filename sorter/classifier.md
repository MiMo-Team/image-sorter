# 图片分类 Skill（classifier）

> 可复用的图片整理流程：先按“人物/对象”分类，再按“日期”二级分类，
> 最后校验输出目录结构。适用于家庭/人物照片的批量归整。

---

## 一、Skill 概要

- **目标**：把一批图片，整理成「人物文件夹 → 日期文件夹 → 文件」的四层结构。
- **输入**：`/Users/gaocangxiong/Work/DevProject/image-sorter/agent_work/file_input`（可含任意层级子目录）。
- **输出**：`/Users/gaocangxiong/Work/DevProject/image-sorter/agent_work/file_output`，其下按人物、再按日期归档（该目录即原“处理好的文件夹”层级，内部再分四个子文件夹）。
- **可自动化部分**：按日期二级分类（`sort-flatten.js` 已具备该能力）。
- **需人工/视觉辅助部分**：判断图片里有哪些人物（成年男性 / 成年女性等），决定归属哪个文件夹。

---

## 二、人物一级分类规则

文件先按“图片内容中出现的人物”归入以下 **四个** 一级文件夹之一：

| 一级文件夹 | 归类规则 |
|-----------|---------|
| `高梓皓`  | 图片属于高梓皓相关（按实际人物判定） |
| `高仓雄`  | 图片属于高仓雄相关（按实际人物判定） |
| `朱莉莉`  | **图片中同时出现“成年男性”和“成年女性”** → 归入朱莉莉 |
| `其他`    | 不属于以上任一情况（无人、无法判定、或其他对象） |

> 说明：目前唯一明确给定的规则是——
> **若图片里既有“成年男性”又有“成年女性”，则分类为“朱莉莉”**。
> `高梓皓` / `高仓雄` / `其他` 的具体判定，请沿用“按图中实际人物归属”的同一原则补充。

分类完成后，把文件分别移动到 `高梓皓`、`高仓雄`、`朱莉莉`、`其他` 四个文件夹内。

---

## 三、第三步：按日期二级分类

分别进入 `高梓皓`、`高仓雄`、`朱莉莉`、`其他` 四个文件夹，
对里面的文件**按日期**再分一层。

**命名规则**：文件名需形如 `YYYY_MM_DD_HH_MM_SS_xxx.扩展名`
（例：`2025_06_10_21_15_22_IMG_5630.MOV`）。

**操作**：取文件名前 3 个下划线之前的部分（`YYYY_MM_DD`），
将下划线替换为点号，生成日期文件夹 `YYYY.MM.DD`，再把该文件移入。

**示例**：
`高梓皓` 文件夹内有：
- `2025_06_10_21_15_22_IMG_5630.MOV`
- `2025_06_11_17_18_23_IMG_5635.JPG`

处理后在 `高梓皓` 内创建：
- `2025.06.10/` → 放入 `2025_06_10_21_15_22_IMG_5630.MOV`
- `2025.06.11/` → 放入 `2025_06_11_17_18_23_IMG_5635.JPG`

> 该项目已提供 `sorter/sort-flatten.js`，可递归遍历并按上述日期规则拍平归类，
> 可直接复用其日期解析逻辑（`utils.findIndex(filename, '_', 2)` 取第三个下划线位置）。

---

## 四、第四步：校验输出结构

整理完成后，检查输出目录格式是否正确：

- **最外层文件夹**：`/Users/gaocangxiong/Work/DevProject/image-sorter/agent_work/file_output`
- **第二层**：四个文件夹 —— `高梓皓`、`高仓雄`、`朱莉莉`、`其他`
- **第三层**：按日期分类的文件夹，命名示例：`2026.03.06`
- **最里层**：具体文件

### 结构示例

```
file_output/
├─ 高梓皓/
│   └─ 2026.03.06/
│       └─ xxx.png
├─ 高仓雄/
│   └─ 2026.03.06/
│       └─ zzz.jpg
├─ 朱莉莉/
│   └─ 2026.02.10/
│       └─ yyy.jpg
└─ 其他/
    └─ 2026.01.01/
        └─ www.png
```

## 五、复用步骤速查（Checklist）

1. **准备输入**：把待整理图片放入 `/Users/gaocangxiong/Work/DevProject/image-sorter/agent_work/file_input`（可含子目录）。
2. **一级分类**：逐张判断图中人物，按「第二节规则」归入 `高梓皓` / `高仓雄` / `朱莉莉` / `其他`。
   - 关键规则：同时含“成年男性”+“成年女性” → `朱莉莉`。
3. **二级分类**：在每个文件夹内，按文件名 `YYYY_MM_DD_...` 解析出日期，建 `YYYY.MM.DD` 子目录并移入。
4. **校验**：确认整体为 `file_output / 四个子文件夹 / 日期文件夹 / 文件` 的四层结构。
5. **输出**：结果落在 `/Users/gaocangxiong/Work/DevProject/image-sorter/agent_work/file_output`，可直接使用。

---

## 六、注意事项

- 文件名必须以 `YYYY_MM_DD_HH_MM_SS` 开头，否则无法正确解析日期，会被当作异常文件处理（参考 `sort-flatten.js` 中的 `mixed` 逻辑）。
- 一级人物分类依赖对图片内容的识别（人工或视觉模型），无法纯靠文件名自动完成。
- 每次重新运行整理脚本前，注意备份已有结果，避免被覆盖。
